Project 2

Word Cloud of Class Objectives

We used students' "dream objectives about the class" from an AI course to generate a word cloud. The visualization highlights the most common aspirations and interests among the students.

Python code snippet (from wordcloud.py)

from wordcloud import WordCloud, STOPWORDS

def generate_wordcloud(text, out_path):
    wc = WordCloud(
        width=1600,
        height=900,
        background_color="white",
        stopwords=STOPWORDS,
        collocations=True,
    ).generate(text)
    wc.to_file(str(out_path))
